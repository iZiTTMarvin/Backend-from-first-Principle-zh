# 后端第一性原理（中文版）

欢迎来到**后端第一性原理**中文版的文档仓库！

本仓库包含一系列涵盖后端工程基础与进阶概念的笔记、代码片段与讲解。这个系列的目标是把复杂的后端主题拆解为可以理解的、最基本的原理。

本项目 fork 自 [@DsThakurRawat](https://github.com/DsThakurRawat) 的 [Backend-from-first-Principle](https://github.com/DsThakurRawat/Backend-from-first-Principle)，并翻译为中文，面向中文开发者。

## 目录

文档按以下主题组织：

1. **HTTP 与 CORS** — 理解 Web 的基础协议与跨域资源共享。
2. **后端路由** — 请求如何被分发到对应的处理器。
3. **序列化与反序列化** — 在 JSON、Protobuf 等格式之间转换数据结构。
4. **认证与授权** — 保护应用并管理用户访问。
5. **校验与转换** — 保证数据完整性与净化。
6. **控制器、服务、仓储与中间件** — 探索分层架构模式与请求上下文。
7. **API 设计（REST API）** — 设计直观且可扩展的 RESTful API 的最佳实践。
8. **数据库** — 后端系统中数据库集成的核心概念。
9. **缓存** — 极速应用背后的秘密（Redis、Memcached 等）。
10. **任务队列与后台任务** — 管理异步工作负载。
11. **全文搜索** — 使用 Elasticsearch 构建快速搜索功能。
12. **错误处理与容错系统** — 构建能优雅处理故障的弹性应用。
13. **gRPC 与服务间通信** — 微服务的高效通信协议。
14. **生产级配置管理** — 安全管理环境变量与配置。
15. **日志、监控与可观测性** — 跟踪系统健康状况并排查生产问题。
16. **优雅停机** — 安全地终止应用，不丢数据、不中断请求。
17. **后端安全** — 保护后端所需的一切（SQL 注入、XSS、CSRF 等）。
18. **后端扩展与性能工程（上）** — 垂直与水平扩展应用的策略。
19. **后端扩展与性能工程（下）** — 进阶扩展技术。
20. **并发与并行** — 理解 IO 密集与 CPU 密集任务及其优化方式。
21. **容器化、部署、Docker、Kubernetes 与 CI/CD** — 一致地打包与交付应用。
22. **自动化测试** — 编写有效的单元、集成与端到端（E2E）测试。
23. **消息代理与事件流** — 使用 Kafka 等工具构建事件驱动架构。
24. **WebSocket 与实时通信** — 使用 WebSocket 构建实时功能。

## 开始使用

浏览各个章节即可探索具体主题。每章都包含详细的笔记、代码示例与可运行的实现。
